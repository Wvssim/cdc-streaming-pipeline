# Frontend

Application Angular du projet — voir [../docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md) pour l'architecture
globale et [../README.md](../README.md) pour démarrer toute la stack.

## Démarrage

```bash
npm install
ng serve
```

Puis ouvrir `http://localhost:4200/`. Les APIs des services (documents-api, audit-service, etc.)
doivent tourner en parallèle — voir la section « Démarrage rapide » du README racine.

## Build

```bash
ng build
```

## Tests

```bash
ng test
```
